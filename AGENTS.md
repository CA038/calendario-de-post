# Reglas del Proyecto - Calendario de Post (Adrian Reyes Creativo)

## 1. Restricción de Navegador
- **PROHIBIDO** abrir Chrome o usar herramientas de navegador (`browser_subagent`). Todas las pruebas y validaciones deben realizarse sin abrir el navegador.

## 2. Resumen Previo Obligatorio
- **Siempre** antes de realizar un cambio o escribir/editar archivos de código, presenta un resumen breve al usuario explicando qué se va a modificar y por qué.

## 3. Análisis Previo Contra Rupturas
- Analiza minuciosamente el código existente antes de cada edición para no romper dependencias, variables o flujos de ejecución.

## 4. Modularidad y Límite de Líneas
- Mantén el código desacoplado y modular. Ningún archivo debe exceder las **1,000 líneas de código**. Separa responsabilidades en módulos pequeños y limpios.

## 5. Estilo de Iconos
- Usar **únicamente iconos de línea** (Lucide Icons en formato SVG). Está estrictamente prohibido usar iconos 3D o estilos pesados.

## 6. Documento de Seguimiento
- Mantener y actualizar el archivo `PROJECT_STATUS.md` en la raíz del proyecto cada vez que el usuario lo solicite, detallando arquitectura, estado actual y funcionamiento.
